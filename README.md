# راية

لعبة استراتيجية برتب مخفية: كل لاعب يرتّب 40 قطعة بسرية، والهدف أسر راية الخصم.
تلعب ضد البوت أو (قريباً) أونلاين ضد ربعك. فيها شكلين يختار منهم اللاعب: «طاولة الحرب» و«صلصال».

## التشغيل

```bash
npm install
npm test        # اختبارات محرك القواعد
npm run dev     # الواجهة على http://localhost:5173
npm run build   # نسخة للنشر في apps/web/dist
```

## البنية

- `packages/engine`: محرك القواعد والبوت (TypeScript بدون أي اعتماديات). نفس الكود يستخدمه المتصفح والسيرفر.
- `apps/web`: الواجهة (React + Vite) مع الثيمين.
